# VoidVerse Android app shell

This folder contains the first real Android app phase for VoidVerse.

## What is included

- Android project skeleton
- Kotlin + Jetpack Compose app shell
- Login/home/shop/avatar UI screens
- Material 3 dark theme
- Play-store style foundation for future work

## How to run

1. Open Android Studio.
2. Open the folder `android/VoidVerseApp`.
3. Let Gradle sync.
4. Run the app on a simulator or connected device.

## Notes

This is Phase 1: a working app shell and screen structure, not a full production multiplayer game or store submission. The next phases are backend API, database, auth, secure inventory logic, and signed release packaging.
