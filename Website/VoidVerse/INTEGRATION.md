# VoidVerse integration

The VoidVerse experience is available at:

- `Website/VoidVerse/index.html` — standalone static hub
- `Website/VoidVerse.aspx` — ASP.NET-friendly launcher/redirect
- The site root (`Website/Default.aspx`) now includes a VoidVerse launch card.

For local testing, serve the `Website` directory with IIS/IIS Express, or open `VoidVerse/index.html` directly in a browser.
